# Amazon Cart Project 🛒

This is a simple, interactive Amazon-style shopping cart project built using **HTML, CSS, and JavaScript**.  
The project demonstrates basic e-commerce functionality where users can add products to a cart dynamically.

---

## 📌 Project Overview

The goal of this project is to simulate a basic online shopping experience similar to Amazon.  
Users can view products and add them to a cart, with JavaScript handling the interactivity and updates without reloading the page.

---

## 🚀 Features

- Product listing display
- Add items to the cart
- Interactive buttons
- Dynamic updates using JavaScript
- Clean and responsive UI
- No page reloads during interaction

---

## 🛠️ Technologies Used

- **HTML** – Page structure  
- **CSS** – Styling and layout  
- **JavaScript** – Interactivity and cart logic  

---


## How to Use

1. Open `index.html` in your browser.
2. Browse the available products.
3. Click **Add to Cart** to add items to your shopping cart.
4. The cart updates interactively with each item added.
